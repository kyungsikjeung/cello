# 레스토랑 반응형 UI 재구성

## 변경 요약

- 충돌하던 대형 타이포·궤도형 갤러리 CSS를 제거하고 레스토랑 정보 탐색 순서에 맞게 렌더러와 CSS를 재구성했습니다.
- 화면을 데스크톱 2열, 태블릿 압축형, 모바일 1열로 분리했습니다.
- 헤더를 실제 고정형으로 바꾸고 모바일 전체 메뉴와 하단 전화/예약 행동바를 추가했습니다.
- Hero, 메뉴 카드, 3장 공간 갤러리, 위치, 예약 영역을 화면 크기에 따라 서로 다른 그리드로 구성했습니다.
