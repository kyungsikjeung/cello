# 프랜차이즈 운영 매거진 디자인 개편

## 변경 요약

- 프랜차이즈 템플릿을 보틀 그린·크림·차트리오즈 중심의 에디토리얼 디자인으로 개편했습니다.
- Hero에 비대칭 세리프 타이포, 회전 브랜드 인장, 세로 그리드와 필름 그레인을 적용했습니다.
- 운영 경쟁력, 지점, 갤러리, 문의 영역의 둥근 카드 반복을 줄이고 비대칭 모서리와 대형 번호를 적용했습니다.
- 390px 모바일에서 `COFFEE` 행이 우측으로 9px 넘치던 여백을 보정했습니다.

## 수정된 파일

- `src/RestaurantTemplate.jsx`
- `src/restaurant.css`
- `README.md`

## 이유와 영향

- 일반적인 카페 랜딩페이지보다 프랜차이즈 브랜드 홍보와 운영 신뢰를 동시에 전달하기 위한 변경입니다.
- CMS의 `category`, `template`, section 데이터 계약과 레스토랑 분기는 유지했습니다.
- 외부 폰트가 없어도 글자가 깨지지 않도록 장식용 영문과 한글 본문의 폴백을 분리했습니다.

## 검증 결과

- `npm test -- --run`: 75/75 통과
- `npm run build`: 통과
- Chromium 기반 인앱 브라우저: 1862×558, 1440×900, 768×1024, 390×844 가로 넘침 0 확인
- 고정 헤더, Hero 한 화면 높이, 제목·설명·CTA·운영 레일 분리 확인
- 작업 중 디스크 공간 부족으로 0바이트가 된 미추적 컴포넌트는 세션 스냅샷과 성공 패치 체인으로 복구했으며, 복구 직후와 디자인 적용 후 각각 75/75 테스트를 통과했습니다.
