# 소형 프랜차이즈 브랜드·지점 템플릿

## 변경 요약

- 음식점 전용 흐름과 분리된 `franchise` 카테고리와 `franchise-brand-01` 템플릿을 추가했습니다.
- 고정 헤더에 브랜드·지점 안내·매장 사진·가맹 문의 이동 메뉴를 구성했습니다.
- 무인 카페와 소형 리테일에도 사용할 수 있는 운영 기반, 복수 지점, 매장 사진, 카카오톡 가맹 문의 섹션을 구현했습니다.
- CMS에서 지점명·상태·주소·운영시간·사진·PC/모바일 초점을 편집하고 지점을 1~30개 범위에서 추가·삭제할 수 있게 했습니다.
- 범용 소형 매장 Hero와 상권별 지점 예시 이미지 4장을 생성해 기본 데이터에 연결했습니다.

## 이유와 영향

- 프랜차이즈 홍보 사이트를 레스토랑의 메뉴·예약 구조에 묶지 않고 `category/template/schema`로 분리해 업종 확장성을 확보했습니다.
- 기존 학원 02B와 레스토랑 전용 데이터·딥링크는 유지됩니다.
- 문의 URL은 현재 샘플 카카오 채널 주소이며 실제 브랜드 채널로 교체해야 합니다.
