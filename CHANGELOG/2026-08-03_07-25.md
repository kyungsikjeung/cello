# 프랜차이즈 경쟁력 섹션 재구성

## 변경 요약

- 동일한 크기의 3개 카드 나열을 제거했습니다.
- 왼쪽은 보틀 그린 브랜드 선언문, 오른쪽은 번호·제목·설명으로 구성된 세로형 가치 목록으로 재구성했습니다.
- 왼쪽 패널에는 저대비 `01` 타이포를 배경 요소로 사용하고, 오른쪽은 얇은 구분선과 작은 상태 표시만 유지했습니다.
- 1440×900에서는 41:59 비대칭 2열, 768px 이하에서는 선언문 다음에 가치 목록이 이어지는 수직 구조를 사용합니다.
- 1862×558 저높이 화면에서는 고정 헤더만큼 오른쪽 목록의 상단 여백을 확보해 세 항목을 모두 한 화면에 표시합니다.
- 모바일에서는 경쟁력 섹션 동안 고정 상담 CTA를 숨겨 첫 번째 항목을 가리지 않도록 했습니다.

## 수정된 파일

- `src/restaurant.css`
- `src/RestaurantTemplate.jsx`
- `README.md`

## 이유와 영향

- 기존 영역은 제목·설명·카드가 모두 같은 아이보리 배경과 동일한 크기로 배치되어 시각적 중심이 약했습니다.
- 데이터 구조와 CMS 입력 계약은 변경하지 않고 동일한 `franchise.advantages` 3개 항목을 다른 레이아웃으로 표현합니다.
- 학원 02B와 레스토랑 템플릿 스타일에는 영향을 주지 않습니다.

- Chromium 768×1024·390×844: 수직 재배치와 가로 넘침 0 확인
