# README 제품 정의와 협업 안내 재구성

## 변경 요약

- 저장소의 제품 정체성을 온결 첼로 단일 사이트에서 다중 업종 웹사이트 빌더 SaaS로 바로잡았습니다.
- 프로젝트 배경, 상용 목표, 현재 구현 범위와 미구현 범위를 분리했습니다.
- 상용 MVP 아키텍처 방향과 최우선 구현 체크리스트를 명시했습니다.
- 협업자가 바로 실행하고 담당 소스를 찾을 수 있도록 시작 가이드와 소스 지도를 추가했습니다.
- 온결 첼로 02B 내용을 제품 본문에서 레퍼런스 구현 영역으로 분리했습니다.
- 1차 상용 MVP와 후속 확장 범위, 초기 Supabase Storage와 후속 R2 경계를 구분했습니다.
- 실제 원격 브랜치 구조와 서버 스키마 범위를 기준으로 문서의 과장·오류를 정정했습니다.

## 수정된 파일

- `README.md`
- `CHANGELOG/2026-08-02_02-44.md`

## 변경 이유

단일 첼로 랜딩페이지가 최종 제품으로 오해되지 않게 하고, 새 협업자가 제품 목표·현재 한계·우선 작업·완료 기준을 같은 문서에서 파악하도록 하기 위해서입니다.

## 영향

문서 구조와 표현만 변경합니다. 애플리케이션 코드와 실행 동작에는 영향이 없습니다. Local MVP의 완료와 실제 상용 보안·클라우드 통합 완료를 명확히 구분합니다.
