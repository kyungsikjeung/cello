# 그린 커피하우스 모션 디자인

## 변경 요약

- Framer Plumbzo의 큰 이미지 Hero, 고정 내비게이션, 둥근 CTA, 순차 등장과 카드 마이크로인터랙션을 분석해 독자적인 모션으로 재구성했습니다.
- Hero·운영 기반·지점·갤러리 이미지에 스크롤 패럴랙스를 적용했습니다.
- 헤더는 Hero 위 투명 상태에서 스크롤 후 딥그린 글래스 상태로 전환됩니다.
- 섹션 제목·설명·카드가 순차적으로 등장하며 지점, 경쟁력, 절차, 문의 CTA에 목적별 호버 반응을 추가했습니다.
- `prefers-reduced-motion` 사용자는 패럴랙스와 등장 효과 없이 콘텐츠를 확인할 수 있습니다.
- 프랜차이즈 기본 콘텐츠와 색상을 딥그린·크림·세이지·커피 브라운의 동네 커피 브랜드로 변경했습니다.

## 수정된 파일

- `src/RestaurantTemplate.jsx`
- `src/restaurant.css`
- `src/data/franchise-site.js`
- `tests/restaurant-template.test.js`
- `README.md`

## 이유와 영향

- 레퍼런스의 전환 리듬과 전환 중심 구조만 참고했으며 로고, 문구, 그래픽과 고유 브랜드 요소는 복제하지 않았습니다.
- 모션은 `requestAnimationFrame`, 가시 영역 제한과 CSS transform을 사용해 레이아웃 재계산 영향을 줄였습니다.
- 레스토랑 전용 색상과 데이터는 유지하고 `.is-franchise` 범위에서만 커피하우스 스타일을 적용합니다.

## 검증 결과

- `npm test -- --run`: 12개 파일, 75개 테스트 통과
- `npm run build`: 통과
- Chrome에서 Framer Marketplace와 Plumbzo 공개 데모를 직접 확인했습니다.
- 로컬 프랜차이즈 화면은 Chrome 로컬 URL 정책 때문에 실화면 캡처가 아직 남아 있습니다.
