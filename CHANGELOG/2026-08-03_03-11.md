# 프랜차이즈 디자인 시안 마감

## 변경 요약

- 스크롤 위치에 따라 데스크톱·모바일 헤더에 현재 섹션을 표시합니다.
- 모바일 전체 메뉴가 열리면 배경 스크롤을 잠그고 Escape 또는 메뉴 이동 후 정상 복원합니다.
- 순환 갤러리는 마우스나 키보드로 조작하는 동안 자동 전환을 멈추고 수동 변경만 안내합니다.
- 모바일 고정 CTA는 Hero와 최종 문의 섹션에서는 숨기고 중간 콘텐츠 구간에서만 노출합니다.
- 구현 방식이 노출되던 갤러리 문구와 샘플 전화번호를 제거하고 지점명·주소 표기를 브랜드 시안에 맞게 정리했습니다.
- 키보드 포커스, 고대비 모드, 블러 미지원 브라우저와 터치 환경의 폴백을 보강했습니다.

## 이유와 영향

- 장식 효과를 추가하기보다 현재 위치, 조작 상태, 상담 동선을 명확히 해 실제 공개 페이지의 신뢰도와 사용성을 높였습니다.
- 전화 상담이 없는 브랜드도 가짜 번호 없이 템플릿을 사용할 수 있도록 레스토랑·프랜차이즈의 전화번호를 선택 필드로 변경했습니다.
- `category`, `template`, 미디어 초점, 최소 3장 갤러리와 공통 렌더러 계약은 유지합니다.
