# 프랜차이즈 버튼 대비와 모션 체계 정리

## 변경 요약

- 프랜차이즈의 CTA와 선택 버튼에 기본·hover·focus 상태별 배경색과 글자색을 명시했습니다.
- 모션을 첫 화면 진입, 스크롤 등장, 직접 조작 피드백의 세 단계로 정리했습니다.
- 브랜드 경쟁력 패널은 좌측 패널 오픈과 우측 항목 순차 등장으로 연결하고 반복 장식 모션은 추가하지 않았습니다.
- `prefers-reduced-motion`에서는 새 진입·화살표 모션을 제거합니다.

## 수정된 파일

- `src/restaurant.css`
- `README.md`

## 이유

- 기존 공통 hover 규칙과 프랜차이즈 전용 규칙이 겹치면서 문의 버튼의 밝은 배경 위 글자가 보이지 않을 수 있었습니다.
- 여러 종류의 모션을 분산 적용하기보다 콘텐츠 위계와 조작 결과를 안내하는 모션 체계가 필요했습니다.

## 영향

- 프랜차이즈 템플릿에만 적용되며 학원 02B와 일반 레스토랑 렌더러의 스타일은 변경하지 않습니다.
- 자동 갤러리와 기존 패럴랙스 동작은 유지합니다.

## 검증 결과

- `npm test -- --run`: 75/75 통과
- `npm run build`: 통과
- `git diff --check`: 통과
- Chrome 1440×900: 헤더·운영 선택·문의 CTA hover의 배경/글자/자식 요소 계산 색상 확인, 가로 넘침 없음
- Chrome 768×1024: 경쟁력 패널과 3개 항목 진입 완료, 가로 넘침 없음
- Chrome 390×844: 경쟁력 패널 680px, 가로 넘침 없음, 브랜드 구간 모바일 CTA 숨김 확인
- Safari·Firefox 실기기 검증은 아직 수행하지 않았습니다.
