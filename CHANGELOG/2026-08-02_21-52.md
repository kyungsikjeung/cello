# 레스토랑 두 번째 템플릿 Local MVP

## 변경 요약

- 학원 `editorial-02b`를 그대로 유지하고 `category/template` 디스패처로 레스토랑 `restaurant-essential-01`을 추가했습니다.
- 레스토랑 Hero, 영업 정보, 추천 메뉴, 3장 갤러리, 위치, 예약·포장 CTA와 전용 CMS 편집 화면을 구현했습니다.
- Hero를 이미지 또는 짧은 MP4로 설정하고 포스터·모바일 대체 이미지·PC/모바일 초점을 편집할 수 있게 했습니다.

## 수정된 파일

- `src/App.jsx`, `src/RestaurantTemplate.jsx`, `src/restaurant.css`
- `src/data/default-site.js`, `src/data/restaurant-site.js`, `src/data/site-schema.js`

- `src/main.jsx`, `src/preview-main.jsx`, `src/admin-main.jsx`
- `tests/site-schema.test.js`, `README.md`, `assets/restaurant-*.png`

## 이유와 영향

- 업종별 조건문 누적 대신 판별 스키마와 전용 렌더러 경계를 세워 세 번째 업종 확장 시 학원 02B의 회귀 위험을 줄였습니다.
- 현재 예약·포장은 외부 URL/전화 연결이며 결제·예약 재고·주문 상태 관리까지 포함하지 않습니다.
- MP4는 Local 원본 재생만 지원하며 운영용 트랜스코딩·CDN은 후속 StorageProvider 범위입니다.

- `npm test`: 59/59 통과
- `npm run build`: 통과, 레스토랑 이미지 4개가 해시 자산으로 포함됨
- 실제 브라우저: 1440px, 768px, 390px에서 전체 섹션과 CTA 렌더링 확인
- Local 소유자 CMS: 학원/레스토랑 전환과 카테고리별 편집 탭·미리보기 확인
