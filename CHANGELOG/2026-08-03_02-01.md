# 데스크톱 Hero 타이포그래피·브라우저 호환 보정

## 변경 요약

- 첨부된 1862×558 화면에서 제목이 겹치고 하단이 잘리는 문제를 수정했습니다.
- Hero 제목 크기를 가로폭과 화면 높이 중 작은 값을 기준으로 계산하도록 변경했습니다.
- Hero의 720px 강제 최소 높이를 제거하고 `100vh`/`100svh` 계약을 사용했습니다.
- 초광폭·저높이 데스크톱과 저높이 모바일에 별도 높이 반응형 규칙을 추가했습니다.
- 고정 헤더 자체의 이동 애니메이션을 제거하고 내부 요소만 등장시켜 브라우저별 헤더 소실 위험을 줄였습니다.
- Safari용 `-webkit-backdrop-filter`, Windows·macOS·한국어 시스템 폰트 fallback과 글꼴 렌더링 속성을 추가했습니다.

## 수정된 파일

- `src/restaurant.css`
- `README.md`

## 이유와 영향

- 기존 제목은 `12.8vw`만 사용해 화면이 넓고 낮을수록 세로 공간보다 지나치게 커졌습니다.
- 제목 각 줄을 100% 폭과 좌·중·우 정렬로 바꿔 긴 CMS 문구에서도 수평 오버플로 위험을 낮췄습니다.
- 레스토랑과 프랜차이즈 모두 동일한 안전한 Hero 크기 계산을 사용하며 프랜차이즈의 그린 스타일은 유지됩니다.
