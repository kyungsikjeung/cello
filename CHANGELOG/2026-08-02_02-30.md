# README 브랜치 현황 간소화

## 변경 요약

- GitHub에서 미리보기 가능한 Mermaid `gitGraph`로 브랜치 구조를 표현했습니다.
- 브랜치 표를 URL·역할·핵심 목표·상태 네 항목으로 간소화했습니다.
- 브랜치 관리 규칙, 커밋 스냅샷, 별도 개발 흐름도를 제거했습니다.

## 수정된 파일

- `README.md`
- `CHANGELOG/2026-08-02_02-30.md`

## 변경 이유

브랜치 현황을 운영 규칙보다 구조와 책임 중심으로 빠르게 파악할 수 있도록 정리하기 위해서입니다.

## 영향

문서만 변경되며 애플리케이션 실행 동작에는 영향이 없습니다. 계획 브랜치의 실제 생성 상태도 표에서 명확히 구분됩니다.

## 검증 결과

- `git diff --check` 통과
- README 로컬 링크 검증 통과
- `npm run build` 통과 (기존 대용량 청크 경고 유지)
