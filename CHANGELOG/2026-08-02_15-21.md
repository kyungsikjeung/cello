# CMS 모바일 작업 헤더와 섹션 탐색 보완

## 변경 요약

- 800px 이하에서 관리자 상단 작업 영역을 브랜드 행과 작업 행으로 분리했다.
- 변경 비교·저장·공개·로그아웃 버튼을 4열 그리드로 배치해 한글이 세로로 깨지지 않게 했다.
- 모바일에서 숨겨졌던 CMS 섹션 탐색을 가로 스크롤 탭으로 노출했다.
- 프로젝트 카드와 JSON 파일 작업은 좁은 화면에서 계속 숨겨 핵심 편집 흐름에 집중하도록 했다.
- Pull Request와 `main`·`CMSV2` push에서 `npm ci`·`npm test`·`npm run build`를 실행하는 GitHub Actions CI를 추가했다.

## 수정된 파일

- `src/cms/admin.css`
- `.github/workflows/ci.yml`
- `CHANGELOG/2026-08-02_15-21.md`

## 이유

PR #2 반응형 회귀 검사에서 390px 관리자 화면의 상단 버튼이 지나치게 압축되어 글자가 세로로 표시됐고, 사이드바가 사라져 다른 편집 섹션으로 이동할 방법도 없었다.

## 영향

- 390px·768px에서 저장과 공개 작업을 읽을 수 있는 크기로 유지한다.
- 모바일에서도 첫 화면·프로그램·강사·위치·디자인·미디어·버전 섹션을 전환할 수 있다.
- 801px 이상 데스크톱 레이아웃에는 영향을 주지 않는다.
- 목적별 PR의 테스트·빌드 회귀를 GitHub에서 자동 차단할 수 있는 기준선을 제공한다.

## 검증 결과

- 랜딩페이지: 1440px·768px·390px에서 가로 overflow와 이미지 로딩 오류 없음.
- 캐러셀: 자동 순환·수동 화살표·모바일 메뉴 동작 확인.
- 관리자: 390px·768px 상단 버튼과 가로 섹션 탭, 1440px 기존 3열 레이아웃 확인.
- 모바일 CMS에서 `첫 화면`에서 `프로그램`으로 섹션 전환 확인.
- `npm test`: 31/31 통과.
- `npm run build`: 통과.
- GitHub Actions: workflow 파일 추가 완료. 원격 runner 결과는 push 후 확인 필요.
